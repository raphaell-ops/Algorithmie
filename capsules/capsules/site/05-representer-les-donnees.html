CAPSULE 05 · REPRÉSENTATION

Le contrat ne dit pas comment stocker

01
Le contrat de ra dit : « le premier devient le dernier ». Il ne dit rien sur la mémoire.
02
Plusieurs représentations respectent le même contrat, et passent les mêmes tests.
03
Elles diffèrent par leur coût : nombre d'écritures, copies, allocations.
C'est pour ça que les tests de la capsule 03 ne regardent que Snapshot() : ils restent valables si on change de représentation.
Choisir une représentation = choisir quelles opérations seront rapides.

CAPSULE 05 · REPRÉSENTATION

Options 2 et 3

Tranche, sommet à la fin

pa/pb = append / retirer le dernier : rapide.

Mais ra/rra déplacent toujours tout : O(n). Or les rotations sont les instructions les plus fréquentes.

Liste chaînée

Toutes les instructions en O(1) si on garde un pointeur sur le sommet et sur le fond.

Mais une allocation par nœud, un pointeur en plus par valeur, et des éléments dispersés en mémoire.

Aucune de ces deux options n'est rapide ET sans allocation.

01
Un tableau de taille fixe N, alloué une seule fois.
02
head = indice du sommet. n = nombre d'éléments.
03
La pile « fait le tour » : après la dernière case, on revient à la case 0.
04
Le petit numéro sous chaque case occupée donne sa position dans la pile (0 = sommet).
On ne déplace plus les éléments : on déplace l'indice head.
Montrer le chemin : case 3, case 4, retour à 0, case 1. La case 2 est libre.
CAPSULE 05 · REPRÉSENTATION

Calculer un indice avec le modulo


// position i (0 = sommet) -> case du tableau
func (d *deque) idx(i int) int {
	return (d.head + i) % len(d.buf)
}

// poser au sommet : head recule d'une case
func (d *deque) pushTop(v int) {
	d.head = (d.head - 1 + len(d.buf)) % len(d.buf)
	d.buf[d.head] = v
	d.n++
}
01
(head + i) % cap : avancer de i cases en faisant le tour.
02
Pour reculer, on ajoute cap avant le modulo.
03
Pourquoi ? En Go, -1 % 5 vaut -1, pas 4. Le résultat garde le signe de la valeur de gauche.
Recul = (head − 1 + cap) % cap. Sans le « + cap », on obtient un indice négatif et le programme plante.

CAPSULE 05 · PRATIQUE

Exercice 2 Poser un élément

Même tampon (head = 4, n = 4). On fait pushTop(7). Que valent head, n et la pile ?

Solution

head = (4 − 1 + 6) % 6 = 3, buf[3] = 7, n = 5. Pile : [7 50 60 10 20].

CAPSULE 05 · PRATIQUE

Exercice 3 Le modulo en Go

Que valent -1 % 5, (-1 + 5) % 5 et (3 + 4) % 5 en Go ? Que se passe-t-il si on écrit head = (head - 1) % cap avec head = 0 ?

Solution

-1, 4, 2. Avec head = 0, on obtient head = -1 et buf[-1] provoque un panic: index out of range.

CAPSULE 05 · SYNTHÈSE

À retenir

01
Le contrat décrit le comportement, la représentation décide du coût.
02
Tranche : simple, mais push ou rotation en O(n). Liste chaînée : O(1), mais une allocation par nœud.
03
Tampon circulaire : tableau fixe + head + n. Tout en O(1), aucune allocation.
04
Indices : (head + i) % cap pour avancer, (head − 1 + cap) % cap pour reculer.
